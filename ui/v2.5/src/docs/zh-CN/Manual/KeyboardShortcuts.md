# 键盘快捷键

## 全局快捷键

| 键盘组合 | 动作 |
|-------------------|--------|
| `?` | 显示手册 |

|-------------------|--------|

| `g l` | 图库 |
| `g p` | 演员 |
| `g u` | 工作室 |
| `g t` | 标签 |
| `g z` | 设置 |

## 查询页面快捷键

| 键盘组合 | 动作 |
|-------------------|--------|
| `/` | 聚焦搜索字段 / 聚焦筛选对话框中的查询字段 |
| `f` | 显示添加筛选器对话框 |
| `r` | 如果按随机排序则重新洗牌 |
| `v g` | 将视图设置为网格 |
| `v l` | 将视图设置为列表 |
| `v w` | 将视图设置为墙 |
| `v t` | 将视图设置为标签器 |
| `+` | 增加缩放滑块 |
| `-` | 减少缩放滑块 |
| `←` | 上一页结果 |
| `→` | 下一页结果 |
| `Shift + ←` | 当前结果页 -10 |
| `Shift + →` | 当前结果页 +10 |
| `Ctrl + Home` | 跳转到第一页结果 |
| `Ctrl + End` | 跳转到最后一页结果 |
| `s a` | 全选当前页 |
| `s n` | 取消全选 |
| `s i` | 反选 |
| `e` | 编辑所选 |
| `d d` | 删除所选 |

## 场景页快捷键

| 键盘组合 | 动作 |
|-------------------|--------|
| `a` | 详情选项卡 |
| `q` | 队列选项卡 |
| `k` | 标记选项卡 |
| `i` | 文件信息选项卡 |
| `e` | 编辑选项卡 |
| `h` | 历史记录选项卡 |
| `,` | 隐藏/显示侧边栏 |
| `.` | 隐藏/显示场景进度条 |
| `o` | 增加 O 计数 |
| `d d` | 删除场景 |
| 评分 ||
| `r {1-5}` | 设置评分（星级） |
| `r 0` | 取消评分（星级） |
| `r {0-9} {0-9}` | 设置评分（小数 - `00` 表示 `10.0`） |
| ``r ` `` | 取消评分（小数） |
| 封面生成 ||
| `c c` | 在当前时间生成截图 |
| `c d` | 生成默认截图 |
| 播放 ||
| `p n` | 播放队列中的下一个场景 |
| `p p` | 播放队列中的上一个场景 |
| `p r` | 播放队列中的随机场景 |
| `Space` | 播放/暂停播放器 |
| `Enter` | 播放/暂停播放器 |
| `←` | 后退 10 秒 |
| `→` | 前进 10 秒 |
| `Shift + ←` | 后退 5 秒 |
| `Shift + →` | 前进 5 秒 |
| `Ctrl/Alt + ←` | 后退 1 分钟 |
| `Ctrl/Alt + →` | 前进 1 分钟 |
| `{1-9}` | 跳转到 10-90% 时长 |
| `[` | 向后拖动 10% 时长 |
| `]` | 向前拖动 10% 时长 |
| `↑` | 调高音量 10% |
| `↓` | 调低音量 10% |
| `m` | 切换静音 |
| `l` | A/B 循环切换。按一次设置起点。再按一次设置终点。再按一次禁用循环。 |
| `Shift + l` | 切换场景结束时的循环播放 |
