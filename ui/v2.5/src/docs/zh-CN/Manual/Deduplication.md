# 重复项检查器

[重复项检查器](/sceneDuplicateChecker)会在你的收藏中搜索在感知上相似的场景。这意味着文件不需要完全相同，即使码率、分辨率和片头/片尾不同，也会被识别出来。

为此，Stash 需要生成所谓的 phash，即感知哈希。与生成精灵图类似，Stash 会从场景中的固定位置提取一组 25 张图片。这些图片会被拼接在一起，然后使用 phash 算法进行哈希计算。随后，该 phash 可用于查找与数据库中其他场景相同或相似的场景。phash 生成可以在扫描期间运行，也可以作为单独的任务运行。

> **⚠️ 注意：** 由于提取截图的工作量较大，生成过程可能需要一段时间。

重复项检查器可以以四种不同的精度级别运行。`Exact`（精确）查找具有完全相同 phash 的场景。这是一项快速且准确的操作，除极少数情况外不会产生任何误报。其他精度级别用于查找彼此在设定距离内的重复文件，这意味着这些场景的 phash 并不完全相同，但非常相似。`High`（高）和 `Medium`（中）仍应产生非常好的结果，几乎没有或完全没有误报。`Low`（低）可能会产生一些误报，但仍可能对查找重复项有所帮助。

> **⚠️ 注意：** 要生成 pHash，Stash 需要未损坏的文件。如果在生成精灵图期间遇到任何错误，则不会生成 pHash。这是为了防止误报。
