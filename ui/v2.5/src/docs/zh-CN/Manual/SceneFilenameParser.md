# 场景文件名解析器

[此工具](/sceneFilenameParser)会解析你媒体库中的场景文件名，并允许根据这些文件名设置元数据。

## 解析器选项

要使用此工具，必须输入一个文件名模式。该模式接受以下字段：

| 字段 | 说明 |
|-------|--------|
| `title` | 在其中捕获的文本会被设置为场景的标题。 |
| `ext` | 匹配文件名的结尾。不被捕获。不包含最后一个 `.` 字符。 |
| `d` | 匹配分隔符字符（`-_.`）。不被捕获。 |
| `i` | 匹配在 `Ignored words`（忽略词）字段中输入的任何被忽略的词。忽略词以空格分隔输入。不被捕获。用于匹配诸如 `DVDRip` 之类的发布产物或发布组。 |
| `date` | 匹配 `yyyy-mm-dd` 并设置场景的日期。 |
| `rating` | 匹配单个数字并设置场景的评分。 |
| `performer` | 根据捕获的文本设置场景演员。 |
| `tag` | 根据捕获的文本设置场景标签。 |
| `studio` | 根据捕获的文本设置工作室。 |
| `{}` | 匹配任意字符。不被捕获。 |

> **⚠️ 注意：** `performer`、`tag` 和 `studio` 字段只会与系统中已存在的演员/标签/工作室进行匹配。

`performer`/`tag`/`studio` 字段在查询之前会移除所有分隔符字符（`.-_`）。名称匹配不区分大小写。

还支持以下部分日期字段。仅当可以使用部分日期组件构建出日期字符串时，才会在场景上设置日期：

| 字段 | 说明 |
|-------|--------|
| `yyyy` | 四位数的年份 |
| `yy` | 两位数的年份。假定前两位数字为 `20` |
| `mm` | 两位数的月份 |
| `mmm` | 三个字母的月份，如 `Jan`（不区分大小写） |
| `dd` | 两位数的日期 |

支持以下完整日期字段，使用与上述相同的部分日期规则：

* `yyyymmdd`
* `yymmdd`
* `ddmmyyyy`
* `ddmmyy`
* `mmddyyyy`
* `mmddyy`

所有这些字段都可以通过 `Add Field`（添加字段）按钮获取。

标题生成还有以下选项：

| 选项 | 说明 |
|--------|--------|
| Whitespace characters（空白字符） | 这些字符会被替换为空白字符（默认为 `._`，用于处理诸如 `three.word.title.avi` 之类的文件名） |
| Capitalize title（标题首字母大写） | 将每个词的首字母大写 |

可以通过 `Display Fields`（显示字段）下拉部分自定义要显示的字段。默认情况下，任何具有新值/不同值的字段都会被显示。

## 应用结果

选项正确后，点击 `Find`（查找）按钮。系统将搜索文件名与给定模式匹配的场景。

结果以表格形式呈现，显示所发现字段的现有值和生成值，并带有一个复选框，用于确定是否在每个场景上设置该字段。这些字段也可以手动编辑。

`Apply`（应用）按钮会根据已设置的字段更新场景。

> **⚠️ 注意：** 结果是分页的，`Apply`（应用）按钮仅应用于当前页面上的场景。
