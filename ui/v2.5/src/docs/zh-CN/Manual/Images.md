# 图片和图库

图片是构成图库的组成部分，但你也可以单独扫描它们。要将图片声明为图库的一部分，有以下四种方式：

1. 将它们一起放在一个文件夹中，并在设置的媒体库部分启用 **Create galleries from folders containing images**（从包含图片的文件夹创建图库）选项。该图库将以文件夹的名称命名。
2. 将它们一起放在一个文件夹中，并在该文件夹中创建一个名为 .forcegallery 的文件。该图库将以文件夹的名称命名。
3. 将它们一起打包成一个 zip 压缩包。该图库将以压缩包的名称命名。
4. 你可以直接在 Stash 中，通过点击图库（Galleries）选项卡中的 **New**（新建）来创建一个图库。

你可以在图库详情页面手动向每个图库添加图片。删除时，可以在同一视图中选择相应的图片，并点击编辑按钮旁边的减号完成。

为获得最佳效果，zip 文件中的图片应在不压缩的情况下存储（具体选项名称取决于你使用的软件，如 copy、store 或 no compression。例如在 Linux 上：`zip -0 -r gallery.zip foldertozip/`）。这会对 zip 读取性能产生**重大**影响。

> **⚠️ 注意：** 目前不支持 ZIP 压缩包中的 AVIF 文件。

> **ℹ️ 注意：** 支持 JPEG XL（`.jxl`），包括在 ZIP 压缩包内部，且需要使用以 `libjxl`（或 [libvips](https://www.libvips.org/)）构建的 FFmpeg。ZIP 压缩包内的 JXL 不会生成感知哈希。

如果图库 zip 文件中某张图片的文件名以 `cover.jpg` 结尾，它会被视为封面，在图库视图页面中最先展示，并作为图库列表视图中的图库封面。如果有多张图片匹配该名称，则选择按自然排序顺序找到的第一张。

你还可以从图库中手动选择任意图片作为其封面。在图库详情页面上，选择所需的封面图片，然后在 ⋯ 菜单中选择 **Set as Cover**（设为封面）。

## 图片片段/gif

图片也可以是片段/gif。这些旨在作为简短的视频循环。目前它们无法在 zip 文件中使用。要将视频文件声明为图片，有以下两种方式：

1. 对所有包含片段/gif 的媒体库停用视频扫描，但保持图片扫描处于活动状态。在设置的媒体库部分设置 **Scan video extensions as image clips**（将视频扩展名作为图片片段扫描）选项。
2. 确保你的片段/gif 所使用的文件扩展名都不在 **Video extensions**（视频扩展名）中，并将它们添加到设置的媒体库部分的 **Image extensions**（图片扩展名）中。

默认情况下，片段/gif 在墙视图和网格视图中显示为静止帧。要查看循环，你可以进入灯箱轮播（例如通过点击墙视图中的某张图片）或图片详情页面。

如果你希望在墙视图和网格视图中将循环用作预览，则需要生成它们。
你可以在扫描新的片段文件时启用扫描设置中的 **Generate previews for image clips**（生成图片片段预览）来完成，也可以在之后通过进入设置任务部分中的 **Generated Content**（已生成内容）部分，启用 **Image clip previews**（图片片段预览）并点击生成来完成。由于文件需要转码，这会花费一些时间。
