# 简介

Stash 通过使用你提供的路径对媒体进行编目来工作。一旦你[配置](/settings?tab=library)了媒体存储的位置，就可以点击 [`Settings -> Tasks`](/settings?tab=tasks) 中的扫描按钮，Stash 将开始扫描并将你的媒体导入其媒体库。

为获得最佳体验，建议在扫描完成后，也生成视频预览和精灵图。你可以在 [`Settings -> Tasks`](/settings?tab=tasks) 中执行此操作。

> **⚠️ 注意：** 目前一次只能执行一个任务。但是，存在一个任务队列，因此你可以将生成任务排队，使其在扫描完成后立即执行。

一旦你的媒体被导入，你就可以开始创建演员、工作室和标签，并整理你的内容了！
