# 识别

识别任务会遍历你的场景，并尝试使用所选的一组抓取源对它们进行识别。如果某个源中找到结果，则该场景会被更新，且不再为该场景检查后续来源。

此任务属于高级设置模式的一部分。

## 规则

- 该任务接受一个或多个抓取器源，包括 stash-box 实例以及支持通过 Scene Fragment 进行抓取的场景抓取器。源的顺序可以重新排列。
- 该任务按提供的顺序遍历抓取器源。
- 如果某个源中找到结果，则该场景会被更新，且不再为该场景检查后续来源。

### Organized 标志

已添加 Organized 标志的场景不会被识别任务修改。你还可以将 Organized 标志状态用作筛选条件。

## 选项

可以配置以下选项：

| 选项 | 说明 |
|--------|-------------|
| Performer genders（演员性别） | 筛选在识别过程中包含哪些演员性别。如果未选择任何性别，则无论性别如何，所有演员都会被包含。 |
| Set cover images（设置封面图片） | 如果为 false，则不会修改场景封面图片。 |
| Set organized flag（设置 Organized 标志） | 如果为 true，当场景被标记为已整理时，会将 organized 标志设置为 true。 |
| Skip matches that have more than one result（跳过具有多个结果的匹配） | 如果未启用此选项且返回多个结果，将随机选择一个进行匹配。 |
| Tag skipped matches with（为跳过的匹配标签） | 如果设置了上述选项且某个场景被跳过，则会添加该标签，以便你可以在场景标签器视图中筛选它并手动选择正确的匹配。 |
| Skip single name performers with no disambiguation（跳过没有消歧信息的单名演员） | 如果未启用此选项，将匹配诸如 Samantha 或 Olga 之类的常见通用演员名。 |
| Tag skipped performers with（为跳过的演员标签） | 如果设置了上述选项且某个演员被跳过，则会添加该标签，以便你可以在场景标签器视图中筛选它并选择如何处理这些演员。 |

### 字段特定选项

每个字段可以有一个策略。每种策略的行为如下：

| 策略 | 说明 |
|----------|-------------|
| Ignore（忽略） | 不设置该字段。 |
| Overwrite（覆盖） | 覆盖现有值。 |
| Merge（合并，*默认*） | 对于多值字段，添加到现有值中。对于单值字段，仅在尚未设置时才设置。 |

对于工作室、演员和标签，有一个 **Create Missing Objects**（创建缺失对象）选项可用。默认启用。当为 true 时，如果在识别过程中包含某个工作室/演员/标签而系统中尚不存在，则会创建它。

## 运行任务

- **Identify...（识别...）：** 从任务页面对整个媒体库运行识别任务。
- **Selective Identify（选择性识别）：** 从 Tasks > Identify...（任务 > 识别...）页面配置并对特定目录运行识别任务。在页面顶部点击文件夹图标以选择目录。

## 日志

每个场景的识别过程结果会输出到日志中。
