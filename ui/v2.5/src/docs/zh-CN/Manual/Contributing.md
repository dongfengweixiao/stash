# 参与贡献的方式

## 资金赞助

欢迎并接受资金赞助，可以通过 [Open Collective](https://opencollective.com/stashapp) 或 [GitHub Sponsors](https://github.com/sponsors/stashapp) 进行。

## 开发相关

Stash 后端使用 Go 编写，采用 SQLite 数据库。UI 使用 Typescript 编写，采用 React。欢迎修复 bug、改进以及新增功能。有关如何入门的详细信息，请参阅 [DEVELOPMENT.md](https://github.com/stashapp/stash/blob/develop/docs/DEVELOPMENT.md) 文件。你可以通过我们的 [Discord](https://discord.gg/2TsNFKt) 获取帮助。

## 文档

改进 Stash 文档的工作有助于新用户，并能减少我们在 Discord 中需要解答的问题数量。欢迎对文档的贡献。虽然通过 GitHub 拉取请求提交文档变更是最理想的方式，我们也乐于接受通过 [GitHub issues](https://github.com/stashapp/stash/issues) 或 [Discord](https://discord.gg/2TsNFKt) 提交的内容。

对于有网页经验的人，我们也欢迎对[网站](https://stashapp.cc/)的贡献（截至撰写时该网站尚不完善）。

## 测试功能、改进和 bug 修复

目前测试由一个非常小的团队负责，因此欢迎新的测试者。能够本地构建 Stash 是最理想的，但拉取请求的二进制文件也可供使用。

首先，你需要登录 GitHub。找到并打开相关的拉取请求，然后点击 `Checks` 选项卡。在右侧应该有一个标题为 `Artifacts` 的按钮——点击它，你会看到一个下拉列表，其中包含从该拉取请求构建的 Linux、Windows 和 macOS 二进制文件的下载链接。

## 提交和参与 bug 报告、改进及新功能

我们欢迎对未来改进和功能的想法，bug 报告对所有人都有帮助。这些都可以在 [GitHub](https://github.com/stashapp/stash/issues) 上找到。

## 提供支持

也欢迎在我们的[社区论坛](https://discourse.stashapp.cc/)和 [Discord](https://discord.gg/2TsNFKt) 上为新用户提供支持。
