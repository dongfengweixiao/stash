# 自动标签

自动标签会根据在文件路径或文件名中找到的名称，自动将演员、工作室和标签分配给你的媒体。此任务适用于场景、图片和图库。

此任务属于高级设置模式的一部分。

## 规则

> **⚠️ 重要：** 自动标签仅对 Stash 数据库中已存在的名称生效。它不会创建新的演员、工作室或标签。

 - 多词名称在词语按顺序出现、且由以下任意字符分隔时匹配：`.`、`-`、`_` 或空白字符。这些分隔符被视为词边界。
 - 匹配不区分大小写，但要求词边界内为完整的词。部分词或拼写错误的词不会匹配。
 - 自动标签不会匹配演员别名。匹配时不会考虑别名。

### 示例（演员 "Jane Doe"）

**匹配：**

| 示例 | 说明 |
|---|---|
| `Jane.Doe.1.mp4` | 以点作为分隔符。 |
| `Jane_Doe.2.mp4` | 以下划线作为分隔符。 |
| `Jane-Doe.3.mp4` | 以连字符作为分隔符。 |
| `Jane Doe.4.mp4` | 以空白字符作为分隔符。 |
| `Mary-Jane-Doe` | 允许在词边界周围存在额外字符。 |
| `Jane-Doe_n` | 允许在词边界周围存在额外字符。 |
| `[OF]jane doe` | 允许在词边界周围存在额外字符。 |

**不匹配：**

| 示例 | 说明 |
|---|---|
| `Maryjane-Doe` | 合并的词，没有分隔符。 |
| `Jane-Doen` | 拼写不匹配。 |

### Organized 标志

已添加 Organized 标志的场景、图片和图库不会被自动标签修改。你还可以将 Organized 标志状态用作筛选条件。

工作室也支持 Organized 标志，但它仅用于信息展示。它作为前端指示，供用户标记某个工作室的收藏集已完整，并不会影响自动标签的行为。要排除某个工作室使其不参与自动标签，应使用忽略自动标签（Ignore Auto tag）标志。

### 忽略自动标签标志

已添加忽略自动标签（Ignore Auto tag）标志的演员或标签会被自动标签任务跳过。

## 运行任务

- **自动标签（Auto tag）：** 你可以从任务页面对整个媒体库运行自动标签任务。
- **选择性自动标签（Selective auto tag）：** 你可以从任务页面对特定目录运行自动标签任务。
- **单独页面：** 你可以从各自的页面对特定演员、工作室和标签运行自动标签任务。

### 禁用确认警告

在自动标签任务运行前会显示一条确认警告。如果你频繁使用自动标签，可以在警告对话框中勾选 **Don't show this warning again**（不再显示此警告）复选框来禁用此警告，或者启用 **Settings** > **Tasks** > **Auto tag** > **Disable auto-tag warning**。
