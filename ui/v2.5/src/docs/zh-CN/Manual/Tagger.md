# 场景标签器

Stash 可以与 stash-box 集成，后者充当集中的元数据数据库。该功能尚处于开发的早期阶段，但已可用于指纹/关键字查询以及对演员和场景的自动标签。批量标签界面可以从[场景视图](/scenes?disp=3)访问。如需更多信息，请加入我们的 [Discord](https://discord.gg/2TsNFKt)。

## 搜索

指纹搜索会将你当前选择的文件与远程 stash-box 实例进行匹配。任何具有匹配指纹的场景都会被返回，但目前不对指纹进行校验，因此建议在保存前再次确认其有效性。

如果没有找到指纹匹配，则可以按关键字进行搜索。该搜索通过将查询与场景的 _标题_、_发布日期_、_工作室名称_ 和 _演员名称_ 进行匹配来工作。默认情况下，标签器使用文件上设置的元数据，或解析文件名，这可以在配置中更改。

需要注意的是，只有当*所有查询词都匹配时*，它才会返回匹配结果。例如，如果一个场景的标题为 `"A Trip to the Mall"`，演员为 `"Jane Doe"`，那么搜索 `"Trip to the Mall 1080p"` 将*不会*匹配，但 `"trip mall doe"` 则会匹配。通常几条信息就足够了，例如演员名 + 发布日期或工作室名。为避免常见的无关关键字，你可以在标签器配置中将它们添加到黑名单中。黑名单中的任何项目都会从查询中被剔除。

## 保存

当场景被匹配后，Stash 会尝试将工作室和演员与你本地的工作室和演员进行匹配。如果你之前已经匹配过它们，则会自动选中。如果没有，你要么从下拉菜单中选择正确的演员/工作室，要么选择创建以创建一个新实体，要么选择跳过以忽略它。

一旦场景被保存，该场景以及匹配的工作室/演员将保存 `stash_id`，该 ID 将用于未来的标签。

默认情况下不显示男性演员，这可以在标签器配置中启用。同样，场景标签默认情况下不会被保存。可以将它们设置为与场景上的现有标签合并，或覆盖现有标签。目前不建议设置标签，因为它们难以去重，并可能使你的数据变得杂乱。

## 提交指纹

场景保存后，系统会提示你将指纹提交回 stash-box 实例。这是可选的，但对于拥有相同或相似副本的其他用户会有所帮助，使他们能够通过指纹搜索进行匹配。Stash 仅发送 `stash_id` 和文件指纹。

提交的指纹通过你的 stash-box API 密钥与你的账户关联，并可在 stash-box 网站上进行管理。Stash 不会存储有关已提交指纹的任何额外信息。如果你在 stash-box 网站上删除了某个指纹，它也会从实例中被移除，并且不再可用于匹配。
