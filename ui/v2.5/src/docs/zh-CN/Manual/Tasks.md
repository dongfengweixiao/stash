# 任务

此页面允许你指示 Stash 服务器执行各种任务。

## 扫描

扫描功能会遍历你已配置的 Stash 目录，查找新文件和已移动的文件。

Stash 目前通过执行快速文件哈希来识别文件。这意味着，如果文件被重命名或移动到你已配置的 Stash 目录内的其他位置，扫描将检测到这一点并相应地更新其数据库。

Stash 目前会忽略重复文件。如果两个文件的内容完全相同，则只使用它遇到的第一个。

### 使用 `.stashignore` 忽略文件

你可以创建 `.stashignore` 文件，将特定文件或目录排除在扫描之外。这些文件使用 gitignore 风格的模式匹配语法。

将 `.stashignore` 文件放在媒体库中的任何目录中。该文件中的规则将应用于该目录内的所有文件和子目录。你可以在目录层次结构的不同层级放置多个 `.stashignore` 文件 - 父目录中的规则会级联到子目录。

zip 文件内部不会读取 `.stashignore` 文件。

**支持的规则：**

| 规则 | 描述 |
|---------|-------------|
| `filename.mp4` | 忽略特定文件。 |
| `*.tmp` | 忽略所有具有特定扩展名的文件。 |
| `temp/` | 忽略目录及其所有内容。 |
| `**/cache/` | 忽略任何层级中名为 "cache" 的目录。 |
| `!important.mp4` | 取反 - 即使匹配了前面的规则，也不要忽略此文件。 |
| `# comment` | 以 # 开头的行是注释。 |
| `\#filename` | 使用反斜杠来匹配字面的 # 字符。 |

**`.stashignore` 文件示例：**

```
# Ignore temporary files
*.tmp
*.log

# Ignore specific directories
temp/
.thumbnails/

# But keep this specific file
!important.tmp
```

扫描任务接受以下选项：

| 选项 | 描述 |
|--------|-------------|
| 生成场景封面 | 为视频文件生成场景封面。 |
| 生成预览 | 生成视频预览（mp4），在鼠标悬停在场景上时播放。 |
| 生成动态图片预览 | *在高级模式下可用* - 还会生成动态（webp）预览，仅在 场景/标记 墙预览 类型设置为 动态图片 时才需要。浏览时它们比视频预览消耗更少的 CPU，但除了视频预览之外还要生成它们，并且文件更大。|
| 生成进度条精灵图 | 显示在视频播放器下方用于方便导航的一组图像。 |
| 生成视频感知哈希 | 生成用于场景去重和识别的感知哈希。 |
| 生成图片缩略图 | 为图片文件生成缩略图。 |
| 生成图片感知哈希 | 生成用于图片去重和识别的感知哈希。 |
| 生成图片片段的预览 | 为图片片段/gif 生成 gif/循环视频作为缩略图。 |
| 重新扫描文件 | 默认情况下，Stash 仅在文件的修改日期自上次扫描以来已更新时才会重新扫描现有文件。启用此选项后，Stash 将重新扫描该路径中的文件，而不考虑文件修改时间。仅在 Stash 需要重新计算视频/图片元数据，或重新扫描图库 zip 时才需要。 |

## 生成的内容

生成的内容提供以下内容：

* 场景封面 - 用作封面图像的场景截图
* 在鼠标悬停在场景卡片上时播放的视频或图片预览
* 视频感知哈希 - 有助于与 StashDB 匹配，并为重复项查找器提供数据
* 精灵图（每个场景各部分的静止画面），显示在场景进度条中
* 显示在标记页面中的标记视频预览
* 场景的转码版本。见下文
* 图库的图片缩略图
* 图片感知哈希 - 可用于识别和去重

生成任务接受以下选项：

| 选项 | 描述 |
|--------|-------------|
| 场景封面 | 为视频文件生成场景封面。 |
| 预览 | 生成视频预览（mp4），在鼠标悬停在场景上时播放。 |
| 动态图片预览 | *在高级模式下可用* - 生成动态预览（webp）。仅在 预览 类型设置为 动态图片 时才需要。需要启用 生成预览。 |
| 场景进度条精灵图 | 显示在视频播放器下方用于方便导航的一组图像。 |
| 标记预览 | 生成从标记时间码开始的视频预览（mp4）。具有明确结束时间的标记在该时间段内运行（可选择由 `Max marker preview duration` 设置限制）；没有结束时间的标记使用 `Default marker preview duration` 设置（默认 20 秒）。两者均可在 `Settings → System → Preview Generation` 下配置。 |
| 标记动态图片预览 | *在高级模式下可用* - 还会生成动态（webp）预览，仅在 场景/标记 墙预览 类型设置为 动态图片 时才需要。浏览时它们比视频预览消耗更少的 CPU，但除了视频预览之外还要生成它们，并且文件更大。 |
| 标记截图 | 为标记生成静态 JPG 图像。仅在 预览 类型设置为 静态图片 时才需要。需要启用标记预览。 |
| 转码 | *在高级模式下可用* - 不支持的视频格式转换为 MP4。允许直接流式传输，而不是实时转码。 |
| 视频感知哈希 | 生成用于场景去重和识别的感知哈希。 |
| 为交互式场景生成热力图和速度 | 为交互式场景生成热力图和速度。 |
| 图片片段预览 | 为图片片段/gif 生成 gif/循环视频作为缩略图。 |
| 图片缩略图 | 为图片文件生成缩略图。 |
| 图片感知哈希 | 生成用于图片去重和识别的感知哈希。 |
| 覆盖现有文件 | 默认情况下，当已生成的文件存在时，不会重新生成。启用此标志后，将重新生成已生成的文件。 |

### 转码

Web 浏览器支持有限数量的视频和音频编解码器和容器。当浏览器支持编解码器和容器时，Stash 将直接流式传输视频文件。最初，当浏览器不支持编解码器/容器时，Stash 不支持查看场景视频，而生成转码是查看这些文件的一种方法。

Stash 后来实现了实时转码，因此转码现在基本上是不必要的。此外，转码会占用大量磁盘空间，并且不保证无损。

### 图片图库缩略图

这些在首次查看图库时生成，因此无需事先生成。

## 清理

此任务将遍历你已配置的媒体目录，并从数据库中删除任何已无法找到的场景。它还会删除随后不再存在的场景的已生成文件。

执行此任务时应小心，特别是在已配置的媒体目录可能因网络问题而无法访问的情况下。

## 导出和导入

导入和导出任务将读取和写入 JSON 文件到已配置的元数据目录。从文件导入将把你的数据库与文件合并。

> **⚠️ 注意：** 完整导入任务在导入前会完全擦除当前数据库。

有关导出的 JSON 格式的详细信息，请参见 [JSON 规范](/help/JSONSpec.md) 页面。

## 备份

备份任务会创建 Stash 数据库和（可选）blob 文件的备份。备份可以下载，也可以输出到备份目录（位于 `Settings > Paths` 下），或在未配置备份目录时输出到数据库目录。

要进行完整备份，必须复制数据库文件和所有 blob 文件。备份以 zip 文件的形式存储，数据库文件位于 zip 的根目录，blob 文件位于 `blobs` 目录中。

> **⚠️ 注意：** 已生成的文件不包含在备份中，因此从备份还原到空系统时，需要重新生成这些文件。

对于仅数据库的备份，只有数据库文件被复制到目标位置。这在执行有风险的操作之前进行快速备份，或者对于不使用文件系统 blob 存储的用户很有用。

## 从备份还原

从备份还原目前是一个手动过程。必须解压数据库备份 zip 文件，并将数据库文件和 blob 文件（如适用）分别复制到数据库和 blob 目录。然后应重启 Stash 以加载还原的数据库。

> **⚠️ 注意：** 仅数据库备份的文件名与原始数据库文件不同，因此在将备份中的数据库文件复制到数据库目录之前，必须将其重命名以匹配原始数据库文件名。原始数据库文件名可以在 `Settings > Paths > Database path` 中找到。
