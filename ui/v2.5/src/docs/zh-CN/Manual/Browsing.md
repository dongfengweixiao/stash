# 浏览

## 查询和筛选

### 关键字搜索

文本字段允许你使用关键字进行搜索。关键字搜索根据对象类型在不同的字段上进行匹配：

| 类型 | 搜索的字段 |
|------|-----------------|
| 场景 | 标题、详情、路径、OSHash、校验和、标记标题 |
| 图片 | 标题、详情、路径、校验和 |
| 分组 | 标题 |
| 标记 | 标题、场景标题 |
| 图库 | 标题、路径、校验和 |
| 演员 | 姓名、别名 |
| 工作室 | 姓名、别名 |
| 标签 | 姓名、别名 |

### 规则

关键字匹配使用以下规则：

- 默认情况下，所有关键字都必须出现在同一个匹配字段中。
- 使用 `or` 关键字或 `|` 符号来匹配任一关键字。
- 你可以在一个查询中组合多个 `or` 集合。
- 使用 `-` 符号来排除关键字。
- `-` 符号不能与 `or` 操作数组合使用。
- 使用引号（`"`）来匹配精确短语。
- 引号也可以转义关键字和符号。
- 在查询开头或结尾的 `or` 被视为字面值。
- 关键字匹配是大小写不敏感的。

#### 示例

| 查询 | 行为 | 解释 |
|---|---|---|
| `foo bar` | 同时要求 `foo` 和 `bar`。 | 两个关键字必须匹配同一个字段。 |
| `foo or bar` 或 `foo | bar` | 匹配 `foo` 或 `bar`。 | `or` 和 `|` 是等价的。 |
| `foo or bar or baz xyz or zyx` | 匹配 `foo`、`bar` 或 `baz` 中的一个，以及 `xyz` 或 `zyx` 中的一个。 | 可以组合多个 `or` 集合。 |
| `foo -bar` | 匹配 `foo`，排除 `bar`。 | `-` 排除关键字。 |
| `-foo or bar` | 被解释为 `-foo` 或 `bar`。 | `-` 不能与 `or` 操作数组合。 |
| `foo or bar -baz` | 匹配 `foo` 或 `bar`，排除 `baz`。 | 排除与 `or` 集合并存应用。 |
| `"foo bar"` | 匹配精确短语 `foo bar`。 | 引号执行精确短语匹配。 |
| `foo "-bar"` | 匹配 `foo` 和字面文本 `-bar`。 | 引号转义关键字/操作符解析。 |
| `"foo bar" or baz -"xyz zyx"` | 匹配 `foo bar` 或 `baz`，排除 `xyz zyx`。 | 引号括起的短语可以与 `or` 和 `-` 一起使用。 |
| `or foo` | 匹配字面的 `or` 和 `foo`。 | `or` 在查询的开头或结尾时为字面值。 |

### 筛选器

可以通过点击查询文本字段右侧的筛选器按钮来访问筛选器。

请注意，每种条件类型只能分配一个筛选条件。

#### regex 修饰符

某些筛选器有 regex 修饰符作为选项。regex 修饰符默认是大小写敏感的。

### 排序和每页数量

当前排序字段显示在查询文本字段旁边，指示当前的排序字段和顺序。每页数量下拉菜单允许从一组标准的每页对象数量中进行选择，并允许设置自定义的每页数量。

### 已保存的筛选

可以通过查询文本字段左侧的书签按钮访问已保存的筛选。可以通过输入筛选名称并点击保存按钮来保存当前筛选。可以通过点击筛选名称旁边的保存按钮，用当前筛选覆盖现有的已保存筛选。还可以通过按筛选名称旁边的删除按钮来删除已保存的筛选。

已保存的筛选按标题字母顺序排序，大写标题排在前面。

### 默认筛选

通过点击已保存筛选菜单中的 `Set as default` 按钮，可以将顶级页面的默认筛选设置为当前筛选。

## 在文件管理器中显示文件

对于基于文件的的场景、图库和图片，可以在 `File Info` 选项卡中使用 `Reveal in file manager` 操作。此操作将打开文件管理器并定位到文件在磁盘上的位置。如果文件管理器支持，该文件将被选中。

仅当从本地回环地址（例如 `localhost` 或 `127.0.0.1`）访问 Stash 时，此按钮才可用，从远程地址访问 Stash 时不会显示。
