# 互动性

Stash 目前支持使用 funscript 文件与 The Handy 设备同步。

为了让 Stash 连接到你的 Handy 设备，必须在 Settings -> Interface（设置 -> 界面）中输入 Handy 连接密钥。

Funscript 文件必须与匹配的视频文件位于同一目录中，并且必须具有相同的基本名称。例如，`video.mp4` 的 funscript 文件必须命名为 `video.funscript`。必须运行一次扫描，才能用匹配的 funscript 文件更新场景。

带有 funscript 文件的场景可以通过 `interactive` 条件进行筛选。
