##### 其他变更：
* 导入/导出的数据库架构（schema）已更改，与之前的版本不兼容。
* 变更日志（Changelog）已从统计页面移至设置页面中的一个章节。
* 若未显式设置标题，对象的标题现在将显示为文件基本名（basename）。`Don't include file extension as part of the title` 扫描标志不再受支持。
* `Set name, date, details from embedded file metadata` 扫描标志不再受支持。此功能日后可能以内置抓取器的形式实现。
