迁移后，请对整个媒体库运行一次扫描以填充缺失的数据，并纳入此前被忽略的相同文件。

### 💥 已知问题和其他变更
* 导入/导出数据库架构（schema）已更改，与上一版本不兼容。
* `Set name, date, details from embedded file metadata` 扫描标志不再受支持。此功能未来可能作为内置抓取器实现。
