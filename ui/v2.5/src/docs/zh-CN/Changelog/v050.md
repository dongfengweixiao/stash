#### 💥 注意：升级后，在运行一次新的[扫描](/settings?tab=tasks)之前，所有场景的文件大小都将显示为 0B。

### ✨ 新功能
* 添加对每个场景对应多个图库（反之亦然）的支持。
* 在 设置/任务 中添加备份数据库功能。
* 添加图库墙视图。
* 为场景、图库和图片添加 organized 标志。
* 允许配置可见的导航栏项。

### 🎨 改进
* 在顶部导航栏添加捐赠按钮。
* 为自动标签任务添加目录选择。
* 添加字符串匹配/不匹配 regex 筛选条件。
* 添加导入文件大小限制的配置选项，并将默认值提高到 1GB。
* 为清理任务添加 dry-run（试运行）选项。
* 更改自定义 CSS 选项时刷新 UI。
* 添加对演员、标签、工作室和电影的批量删除。
* 扫描/清理后重置缓存以确保场景被更新。
* 添加更多视频/图片分辨率标签。
* 添加在从扫描任务填充时从场景标题中去除文件扩展名的选项。
* 图片灯箱的分页支持和一般性改进。
* 为 CDP 抓取器添加鼠标点击支持。
* 在演员和工作室内页面添加图库标签页。
* 在抓取器页面添加图库抓取器。
* 添加在抓取器中设置 cookie 的支持。
* 截断长文本并在悬停时显示。
* 在缺少图片时以文字形式显示场景工作室。
* 对标题和电影名称使用自然排序。
* 支持在扫描期间可选地生成预览和精灵图。
* 支持为扫描和生成配置可变的线程数。

### 🐛 问题修复
* 修复取消设置图片工作室时的错误。
* 修复创建演员时发生错误导致输入字段被清空的问题。
* 修复点击 O 计数器、Organized 或收藏按钮时编辑数据丢失的问题。
* 将 `generated` 目录中的媒体排除在媒体库之外。
* 防止在场景文件哈希更改时错误地重新生成封面图片。
* 修复版本检查有时给出不正确结果的问题。
* 修复 Stash 首次运行时可能删除 `downloads` 目录的问题。
* 修复生成路径含特殊字符时精灵图生成的问题。
* 防止工作室被设置为自身的父级
* 修复演员抓取器选择框与搜索结果重叠的问题
* 修复标签/工作室图片在更新后未被更改的问题。
* 修复分辨率标签以及对纵向视频和图片的查询。
* 更正 32 位平台上的文件大小
* 修复登录重定向以记住当前页面。
* 修复场景标签器配置保存问题
