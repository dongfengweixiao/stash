### ✨ 新功能
* 添加 stash-box 演员标签器。
* 自动标签器现在会为图片和图库标签。
* 为演员和工作室添加评分字段。
* 支持从特定目录位置提供 UI。
* 为演员添加详情、逝世日期、发色和体重。
* 为演员抓取器添加 `lbToKg` 后处理动作。
* 为工作室添加详情。
* 添加[感知重复项检查器](/sceneDuplicateChecker)。
* 添加各种 `count` 筛选条件和排序选项。
* 为场景、图库、电影、演员和工作室添加 URL 筛选条件。
* 在 `/healthz` 添加用于健康检查的 HTTP 端点。
* 为图库、工作室、电影和标签添加随机排序选项。
* 支持通过 API key 在未登录情况下访问系统。
* 添加场景队列。

### 🎨 改进
* 改进使用网络存储时的精灵图生成性能。
* 抓取元素列表时去除重复值。
* 改进自动标签器的性能。
* 为每个场景生成内容后清理生成的产物。
* 清理 `tmp` 和 `downloads` 生成文件夹耗时超过一秒时在启动时记录日志。
* 默认按场景编号对电影场景排序。
* 在抓取器中支持 http 请求头。
* 在场景/图片/图库卡片和详情中按性别对演员排序。
* 在演员/工作室/标签卡片上为场景/图片/图库添加弹出按钮。
* 为图片墙视图添加幻灯片。
* 支持通过 URL 查询参数传递 API key，并在场景文件信息中的流链接中添加 API key。
* 重做设置向导和迁移 UI。
* 更改页码时滚动到顶部。
* 在抓取器中为 `parseDate` 支持 `today` 和 `yesterday`。
* 默认禁用场景/标记墙预览的声音。
* 改进电影 UI。
* 将演员文本查询更改为仅按姓名和别名搜索。

* 修复未连接互联网时登录页面卡住的问题。
