### ✨ 新功能

* 标记现在具有可选的结束时间。([#5311](https://github.com/stashapp/stash/pull/5311), [#5633](https://github.com/stashapp/stash/pull/5633))
* 标记时间现在具有亚秒级精度。([#5431](https://github.com/stashapp/stash/pull/5431))
* 为标记新增了网格视图。([#5443](https://github.com/stashapp/stash/pull/5443))
* 场景标记现在可以按其时长筛选和排序。([#5472](https://github.com/stashapp/stash/pull/5472))
* 为演员新增了自定义字段。([#5487](https://github.com/stashapp/stash/pull/5487), [#5632](https://github.com/stashapp/stash/pull/5632))
* 为标签新增了排序名称。([#5531](https://github.com/stashapp/stash/pull/5531))
* 新增了图片抓取。([#5562](https://github.com/stashapp/stash/pull/5562))
* 现在可以为 stash 抓取器来源配置 API key。([#5474](https://github.com/stashapp/stash/pull/5474))

### 🎨 改进

* 将对象筛选选择器中的修饰符按钮改为可选项。([#5203](https://github.com/stashapp/stash/pull/5203))
* 将分组详情图片改为可翻转的正反面，而不是同时显示两面。([#5367](https://github.com/stashapp/stash/pull/5367))
* 演员选择现在会根据日期字段显示演员年龄。([#5110](https://github.com/stashapp/stash/pull/5110))
* Stash ID 现在具有更新时间字段。([#5259](https://github.com/stashapp/stash/pull/5259))
* 演员去世日期现在会从 stash-box 获取。([#5653](https://github.com/stashapp/stash/pull/5653))
* 批量演员更新现在会处理在 stash-box 上合并的演员。([#5664](https://github.com/stashapp/stash/pull/5664))
* 任务现在显示预计完成时间（ETA）。([#5535](https://github.com/stashapp/stash/pull/5535))
* 生成交互式热力图时，场景的更新时间字段现在会被更新。([#5401](https://github.com/stashapp/stash/pull/5401))
* Handy 现在会自动重新同步。([#5581](https://github.com/stashapp/stash/pull/5581))
* 现在可以在 stash 抓取器中按场景名称查询。([#5722](https://github.com/stashapp/stash/pull/5722))
* 新增了按 Scene Code 排序的选项。([#5708](https://github.com/stashapp/stash/pull/5708))
