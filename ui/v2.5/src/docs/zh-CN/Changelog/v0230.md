### ✨ 新功能
* 在场景预览底部边缘新增了可悬停控件，用于在场景中拖动定位。([#4022](https://github.com/stashapp/stash/pull/4022))
* 新增了对图片和图库支持多个 URL 的支持。([#4000](https://github.com/stashapp/stash/pull/4000)/[#4114](https://github.com/stashapp/stash/pull/4114))
* 新增了在标签器视图中保存场景时将场景标记为“已整理”的选项。([#4031](https://github.com/stashapp/stash/pull/4031))
* 为场景播放器新增了 A/B 循环支持。([#3904](https://github.com/stashapp/stash/pull/3904))
* 为重复检查器新增了新的选择选项。([#4006](https://github.com/stashapp/stash/pull/4006))

* 重构了演员选择控件以提升性能并显示相关别名。([#4013](https://github.com/stashapp/stash/pull/4013))
