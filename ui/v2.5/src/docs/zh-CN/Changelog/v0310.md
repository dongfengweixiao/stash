### API 变更

* 许多新组件现在可被 patch。([#6468](https://github.com/stashapp/stash/pull/6468), [#6463](https://github.com/stashapp/stash/pull/6463), [#6482](https://github.com/stashapp/stash/pull/6482), [#6492](https://github.com/stashapp/stash/pull/6492), [#6470](https://github.com/stashapp/stash/pull/6470))
* 在插件 API 中新增了对 `ReactFontAwesome` 的访问。([#6487](https://github.com/stashapp/stash/pull/6487))
* 新增了 `destroyFiles` mutation，用于从数据库删除文件条目。([#6437](https://github.com/stashapp/stash/pull/6437))
* 为 destroy 输入新增了 `destroy_file_entry` 标志，用于在销毁场景、图片和图库时删除文件条目。([#6437](https://github.com/stashapp/stash/pull/6437))
* 为 `folder` 类型新增了 `basename` 和 `parent_folders` 字段。([#6494](https://github.com/stashapp/stash/pull/6494))
* 为 `FolderFilterType` 新增了 `basename` 筛选字段。([#6494](https://github.com/stashapp/stash/pull/6494))
* 为 `GalleryFilterType` 新增了 `parent_folder` 筛选字段。([#6636](https://github.com/stashapp/stash/pull/6636))
* 演员 `career_length` 字段已弃用，建议使用 `career_start` 和 `career_end`。
