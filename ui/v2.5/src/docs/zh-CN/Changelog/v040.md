### ✨ 新功能
* 添加选择性扫描。
* 添加对所有对象的选择性导出。
* 在场景页面添加 stash-box 标签器。
* 在场景页面添加筛选标签页。
* 在场景播放器中添加可选的流式传输质量配置。
* 添加图库元数据抓取。
* 添加抓取器列表设置页面。
* 添加对单张图片和手动创建图库的支持。
* 为图库添加各种字段。
* 添加从 zip 文件的部分导入。

### 🎨 改进
* 添加等于/不等于字符串条件。
* 将页面大小上限提高到 1000，并添加新的页面大小选项。
* 添加在按查询 URL 抓取时对查询 URL 参数进行 regex 替换的支持。
* 在 isMissing 筛选器中包含空字段
* 如果缺少预览视频，则在场景墙上显示静态图片。
* 为场景和图库查询添加路径筛选器。
* 在场景页面添加隐藏左侧面板的按钮。
* 在工作室页面添加到父工作室的链接。
* 添加缺失场景的电影筛选器。
* 在场景卡片上添加图库图标。
* 在演员国旗上添加国家查询链接。
* 改进图库布局。
* 添加播放场景预览前的悬停延迟。
* 鼠标移出场景卡片时重新显示预览缩略图。

### 🐛 问题修复
* 将启动行为更改为仅在尚未设置时才从 `STASH_STASH` 环境变量设置媒体库。
* 创建工作室时不设置默认的工作室图片。
* 为网站更新更新 Freeones 抓取器。
* 修复无效的日期标签阻止视频文件被扫描的问题。
* 修复从场景抓取对话框创建电影时的错误。
* 修复不正确的日期时区。
* 修复工作室、标记和图库的搜索筛选器未持久化的问题。
* 修复移动平台上墙项目的待处理缩略图问题。
* 修复 ffmpeg/ffprobe 的下载和权限问题。
